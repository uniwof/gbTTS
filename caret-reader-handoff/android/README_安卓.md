# 光标朗读 · 安卓版 v0.2（离线中文语音引擎）

装好以后，它就是手机系统里的一个“文字转语音引擎”。微信读书、静读天下（Moon+ Reader）以及任何使用安卓系统朗读功能的 App 都可以用它朗读，全程离线、不联网（安装包没有申请任何权限，包括网络权限）。

## 两个版本（任选一个，也可以都装）

| 文件 | 大小 | 音色 | 适合 |
|---|---|---|---|
| 光标朗读_安卓_标准版_v0.2.apk | 约 440 MB | 7 个女声（和 Windows 标准版相同）：女声 1 自然 (Melo，中英双语)、女声 2 柔和 / 3 低沉 / 4 清亮 (zh-ll)、女声 5 温婉 / 6 沉静 / 7 知性 (fanchen-C) | 内存 3 GB 以上的手机 |
| 光标朗读_安卓_轻量版_v0.2.apk | 约 168 MB | 1 个女声 (Matcha)，最快、最省内存 | 老手机、内存小的手机 |

要求：安卓 6.0 或更新；手机芯片 arm64 或 armv7（绝大多数手机都是）。

## 安装和设置（3 步）

1. 把 APK 传到手机上点开安装（第一次会提示“允许安装未知来源应用”，允许即可）。
2. 打开“光标朗读”，点 **打开系统语音设置** → 在 **首选引擎** 里选 **光标朗读**。
   （不同品牌手机的路径大致是：设置 → 辅助功能 / 更多设置 → 文字转语音输出。）
3. 在阅读 App 里打开“听书 / 朗读 / TTS”，选择系统语音（或直接选“光标朗读”）即可。

## 设置界面里能调什么

- **音色**：点一下就切换。同一模型里的音色切换是瞬间的；换到另一个模型要加载几秒。手机内存里同一时间只放一个模型。
- **标点停顿（秒）**：逗号/顿号 0.15、句号/感叹号/问号 0.5、分号 0.3、冒号 0.25、换行 0.5（和 Windows 版一样，可以加减）。
- **基础语速**：默认 1.0。阅读 App 里设置的语速、音调会在这个基础上生效（App 调快时，标点停顿也按比例缩短）。
- **线程数**：默认 2，低端手机保持 2 即可。
- **恢复默认**：停顿、语速、线程数回到默认（音色不变）。

## 说明

- 第一次朗读（或刚换了模型）要先把模型从安装包里读进内存：标准版 Melo 约 3–10 秒，其它音色 1–5 秒，之后就很快。
- 所有 App 都不再使用朗读时，引擎会自动释放模型内存；下次朗读重新加载。
- 两个版本的包名不同（app.caretreader.tts / app.caretreader.tts.lite），可以同时安装。
- 以后的新版本用同一个签名，可以直接覆盖安装升级。
