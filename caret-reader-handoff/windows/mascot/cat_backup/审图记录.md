# 悬浮球小猫 审图记录（sweety-image-art-direction，插画模式：项目色板 = 黑/白/灰）

参考（只学画法）：桌宠项目 Pawli / desk-madeline / DPets 都用小尺寸精灵图 + 分层窗口；日式极简界面要求黑白灰、粗细一致的墨线、大形不碎。

## 第 1 轮（初稿）
- 内容错误：头顶“墨团花纹”在 60px 下看不出是花纹，像缺了一块；看书眼和睡觉眼形状一样，分不出状态。
- 风格偏离：无。
- 层次问题：耳朵顶到球的外圈，画面挤；书页三条细线在 60px 下变成灰糊（稀碎）；念书的嘴太小，60px 下看不出在说话。
- 个人偏好：无。
- 结论：退回 —— 整体缩小 14% 留呼吸空间，去掉头顶花纹，书页改两条粗线，嘴放大。

## 第 2 轮
- 内容错误：无。
- 风格偏离：“压低眼皮”的看书眼读起来像不耐烦、翻白眼，不可爱。
- 层次问题：已解决（有留白，书页清楚，嘴在 60px 可辨）。
- 个人偏好：无。
- 结论：退回 —— 只改眼睛：看书 = 偏下的实心圆眼。

## 第 3 轮
- 内容错误：睡觉眼画成了 ∩（动漫里是“开心眯眼”），改成 ︶。
- 风格偏离：无。层次问题：无。个人偏好：无。
- 结论：通过（改完睡觉眼后再看了一遍放大图和 60px 图）。
