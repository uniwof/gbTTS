# 光标朗读 v0.6（Windows 10 / 11 · 64 位 · 离线）

把光标放在文章里，按一下快捷键，程序就从光标位置开始一直读到文末；
**选中一段文字再按快捷键，就只读选中的部分，读完自动停**；
再按一下暂停，再按一下从停下的地方继续；想彻底停止就按“停止”快捷键。
完全离线，不联网，不需要显卡，也不需要另外安装 .NET。

---

## 一、怎么运行

1. 把压缩包**整个解压**到一个文件夹（例如 `D:\光标朗读`）。不要在压缩包里直接双击运行。
2. 确认文件夹里有这些东西（缺一不可，要放在一起）：
   ```
   CaretReader.exe          ← 双击它运行
   onnxruntime.dll
   sherpa-onnx-c-api.dll
   edition.txt              ← 版本名（标准版 / 轻量版）
   voices\                  ← 「音色」文件夹：每个子文件夹是一个音色包
   frontend\                ← v0.5：多音字词库（不要删；删了会退回旧的读法）
   用户自定义词库.txt        ← v0.5：你自己改读音的地方（见“四之二”）
   THIRD_PARTY_NOTICES.txt  ← 第三方许可（也可以在“设置 → 关于 / 第三方许可”里看）
   licenses\                ← 许可证全文
   ```
3. 双击 `CaretReader.exe`。屏幕右下角会出现一个圆形的**悬浮小人**（在看书），加载时它闭着眼睛，外圈有一圈进度（几秒钟）。
4. 打开记事本或 Word，把光标点到想开始的位置，按 **Ctrl + Alt + R** 开始朗读。
5. 读的过程中再按 **Ctrl + Alt + R** → **暂停**；再按一次 → 从停下的地方**继续**。
6. 按 **Ctrl + Alt + S** → **彻底停止**。之后再按 Ctrl + Alt + R，会重新从光标处开始读。

> 第一次运行时 Windows 可能弹出“Windows 已保护你的电脑”（因为程序没有数字签名）。
> 点“更多信息” → “仍要运行”即可。

## 二、右下角的悬浮小人（v0.6 新界面）

| 操作 | 作用 |
|---|---|
| **单击** | 没在读：从光标处开始朗读（选中了文字就只读选中的）；正在读：**暂停**；已暂停：**继续** |
| **双击** | **停止** |
| **右键** | 菜单：暂停/继续、停止、选择音色 / 试听（每个音色右边的小喇叭）、导入音色包、**始终置顶**（开/关）、外观（看书的小人 / 简单圆球）、设置、关于、退出 |
| **按住拖动** | 移到任意位置，下次打开还在那里 |
| 鼠标停在上面 | 显示当前状态和快捷键提示 |

- 小人平时在看书（偶尔眨眼、翻页）；朗读时一边看书一边念，**嘴巴跟着声音开合**；暂停时抬头看你；加载时闭眼睡觉。
- **点它不会抢走焦点**：记事本、Word、浏览器里的光标位置和**选中的文字**都不会丢。
- **始终置顶**（右键菜单里，默认打开）：像输入法的状态条一样一直在最前面。关掉后它可能被别的窗口挡住，
  这时单击任务栏右下角托盘里的“光标朗读”图标，它会回到屏幕右下角。
- 觉得小人动来动去分心，或电脑特别老：右键 → 外观 →「简单圆球」，完全不动，最省资源。
- 快捷键在本程序**不在前台**时也有效（系统级快捷键）。

## 三、默认快捷键和设置

- 默认快捷键：
  - **Ctrl + Alt + R**：开始 → 暂停 → 继续 → 暂停 …
  - **Ctrl + Alt + S**：彻底停止。
- 点“设置”可以修改：
  - **快捷键**（两个，各有一个输入框）：点输入框，直接按下新的组合键。按 Backspace 恢复这一项的默认值。
    - 字母 / 数字键至少要配两个修饰键（例如 Ctrl+Alt+R、Ctrl+Shift+F）；F1–F12 等功能键配一个就行（例如 Ctrl+F8）。
    - 不能用：Ctrl+C / V / X / Z / Y / A / S、Alt+F4、Alt+Tab 等常用键或系统键；两个快捷键也不能相同。
      输入框下面会用小字说明原因，“保存”不会生效。
    - 如果新快捷键已经被别的程序占用，会弹出提示，并继续使用原来的快捷键（不会把用不了的键保存下来）。
  - **语速**：默认 1.00（原速）。建议保持 1.00，用“标点停顿”来调节节奏。
  - **线程数**：默认 2。电脑较好可以调到 4，会更快；改完会自动重新加载模型。
  - **标点停顿（秒）**：逗号 0.15 / 句号 0.5 / 分号 0.3 / 冒号 0.25 / 换行 0.5。
  - **总在最前**：悬浮小人是否始终显示在其它窗口上面（右键菜单里也能开关）。
- 设置保存在 `settings.json`：
  - 程序文件夹可以写入时，就放在 exe 旁边；
  - 否则放在 `%AppData%\CaretReader\settings.json`。
  - 设置窗口底部会显示实际路径。也可以用记事本直接改这个文件（改之前先退出程序）。
- 日志 `log.txt` 和 `settings.json` 在同一个文件夹，记录每次是用哪种方式取到文字、加载用时等。
- v0.3 起：加载模型的每一步都会先写进 `log.txt`；万一程序意外退出，下次启动时会把“停在哪一步”和 Windows 事件日志里的错误记录补写进 `log.txt`。遇到问题时把 `log.txt` 发出来即可。

## 四、音色（v0.4：音色和程序分开了）

程序文件夹里的 `voices` 文件夹就是「音色」文件夹，里面**每个子文件夹是一个音色包**
（模型文件 + `voice.json` 说明 + `sample.mp3` 试听）。

- **加音色**（两种方法，任选一种）：
  1. 点下拉框右边的 **「+」**，选择音色包文件夹（下载的 zip 先解压；选解压出来的文件夹或它里面那一层都可以，任何盘、中文路径都没问题）。
     程序会检查音色包是否完整，再复制进 `voices`，**不用重启**，马上就能在下拉框里选到。
  2. 直接把音色包文件夹复制到 `voices` 文件夹里，然后点一下音色下拉框，新音色就会出现。
- **删音色**：程序里没有删除按钮——把 `voices` 里对应的文件夹删掉就行（建议先退出程序，或先换成别的音色）。
- 坏掉的音色包（缺文件、`voice.json` 写错）会被跳过，不会让程序出错，原因写在 `log.txt` 里。
- 同一个模型的几个音色（例如 zh-ll 的 0/1/2/3/4 号）互相切换是瞬间的，不用重新加载。
- 用「+」导入时，如果和已有音色包里的模型文件一模一样，程序会用“硬链接”，不重复占硬盘（U 盘等不支持时就普通复制）。

| | 标准版 | 轻量版 |
|---|---|---|
| 内置音色 | 女声 · 自然 (Melo)、男声 · 沉稳 (zh-ll #1) | 女声 · 标准 (Matcha)、男声 · 清朗 (Piper chaowen) |
| 内存（沙盒实测峰值） | 约 250–370MB（同一时间只加载一个模型） | 约 250MB |
| 速度 | Melo 稍慢，低配电脑上建议用 zh-ll / fanchen 音色 | 最快，任何电脑都流畅 |
| 英文 | Melo 可以读英文 | 不读英文（会跳过英文单词） |

两个版本是同一个程序，只是 `voices` 里放的音色不同；其余音色可以单独下载音色包导入，两个版本通用。
音色在下拉框里显示的名字可以在音色包的 `voice.json` 里用记事本改（`name` 那一项）。

## 四之二、多音字（v0.5 新增）

v0.5 起，程序会先按词判断多音字该怎么读（银行 / 行走、还钱 / 还是、长江 / 长大……），再交给声音模型朗读。
内置一个约 27.7 万词的多音字词库（来源都是 MIT / Apache 开源数据，见“关于 / 第三方许可”），
外加原来的上下文规则（还 / 了 / 得 / 着 / 地 / 的 等）和 2,512 个生僻字的读音。

**遇到读错的词，可以自己改**：用记事本打开程序文件夹里的 `用户自定义词库.txt`，每行写一个词和它的拼音：
```
银行 yin2 hang2
六安 lù ān
单老师 shan4 lao3 shi1
```
- 拼音写数字调（hang2）或带调号（háng）都行；轻声写 5（de5）；ü 写成 v。
- 这里的词**优先级最高**，会覆盖内置词库和规则。保存后**重新启动**光标朗读生效。
- 字数和拼音个数对不上的行会被跳过（原因记在 log.txt 里）。
- 原来写在程序里的 11 条修正（数一数、背着、睡着……）已经搬进这个文件，可以随意改。

注意：只对 v0.5 的音色包生效（音色包里有 `pua_map.txt`）。旧版音色包照样能用，只是按原来的方式读多音字。

## 五、界面风格

日式极简：只用黑、白、灰；1 像素黑色细线边框；纯色平涂，没有渐变和阴影；按钮、输入框和窗口用苹果式的柔和圆角；
背景是纸白底色加一层极淡的“网点纸”纹理，像印刷品；按钮悬停时铺网点，按下或“正在朗读”时反白（黑底白字）。
所有尺寸按 8 像素网格排布，字体优先使用“微软雅黑 UI”。

## 六、已知限制

- 只支持 Windows 10 / 11 的 64 位系统（Win7 版本另行制作）。
- 程序没有数字签名，第一次运行可能被 SmartScreen 或杀毒软件提示。
- 取文字有两种方式：
  1. **UI Automation**（首选）：不碰剪贴板，不改动文档。记事本、Word 等大多支持。
  2. **剪贴板**（备用）：当程序不支持第 1 种方式、而且焦点确实在**文字编辑框**里（记事本、Word、写字板、WPS 等）时，
     会自动模拟 Ctrl+Shift+End → Ctrl+C 复制光标后的文字，然后按 ← 取消选中并把剪贴板恢复原样。
     - 这期间屏幕上会**闪一下选中效果**。
     - 在命令行 / 终端、文件夹窗口、桌面等地方**不会**使用这种方式（在终端里按 Ctrl+C 会中断正在运行的程序），
       这时小人旁边会提示“这个窗口不支持朗读”。
     - 只恢复常见格式（文字、RTF、HTML、文件列表、图片）；其它软件私有的格式（例如 Excel 的特殊格式）不会恢复。
     - **隐私提醒**：如果你打开了 Windows 的“剪贴板历史”（Win+V）或“跨设备同步剪贴板”，
       被复制的那段文字可能会留在剪贴板历史里（这是目标程序执行复制时由 Windows 记录的，本程序无法阻止）。
       程序还原剪贴板时已经标记“不记入历史、不上传云端”，不会再多记一条。
       介意的话可以在 Win+V 里手动删除那一条，或在“设置 → 系统 → 剪贴板”里关闭剪贴板历史。
- **选中朗读**（v0.4）：有选中的文字时只读选中部分，读完自动停；没选中就从光标读到文末。
  - 程序先用 UI Automation 读选区；读不到时，在文字编辑窗口里会先按一次 Ctrl+C 看看有没有选中内容（不会改动选区，剪贴板会还原）。
  - Notepad++、VS Code、Sublime 等编辑器在没选中时按 Ctrl+C 会复制整行，所以在这些编辑器里如果 UI Automation 读不到，
    会照旧从选中部分的开头读到文末。
- 停止是立即的（声音马上停）；但如果此刻正在合成某一句，后台会把这一句合成完再丢弃（不到 1 秒），这期间切换音色会稍等一下（小人旁边显示“正在停止…”）。
- 暂停时声音马上停住；后台最多再提前合成约 8 秒的内容就会停下等待，不会一直占用 CPU 和内存。继续时从停下的地方接着读。
- 很长的文档：先取光标后约 2000 字立刻开始读，剩下的部分（最多 10 万字）在后台继续读取，不影响出声速度。
- 读到数字、日期时由模型自带的规则转成中文读法，个别写法可能读得不理想。
- 第一句：太长时会自动在自然断点（空格、“的/了”等之后）切短，通常 1 秒内出声；较慢的音色如果第一句很短，会多攒一点再出声（最多等 1 秒），避免开头多出空白。
- 没有标点的长句会在 36 字以内的自然断点切开，尽量不切断英文单词、数字、网址或表情符号；
  实在没有可切的地方（例如很长的英文连字符串）就在 36 字处直接切开，保证不会卡住或占用大量内存。
- “读不出来”的长字符串会简化：超过 36 个字符的网址读作“链接”；哈希值、订单号这类 16 位以上的字母数字混合串读作“一串字符”；
  16 位以上的纯数字读作“一串数字”。短网址照常朗读。
- 数字中的 3.14、1,000、10:30、10：30、１，０００ 不会被当作标点停顿；Mr. / e.g. 等缩写后不停顿；网址整段保留。
- Melo 音色在很慢的电脑上可能偶尔在句间多停顿零点几秒（合成追不上播放），换成 zh-ll / fanchen 音色即可。

## 七、需要在真机上测试的项目（请帮忙确认）

1. 程序能否正常启动、右下角出现悬浮小人、外圈进度走完。
2. **记事本**（Win10 旧版和 Win11 新版）：光标放在中间，按 Ctrl+Alt+R，是否从光标处开始读？`log.txt` 里写的是“UIA”还是“剪贴板”？
3. **Word**：同上；表格、带图片的文档是否正常；从选中文字开始是否正常。
4. 其它常用软件（WPS、浏览器文本框、写字板）：能不能读？用的哪种方式？剪贴板方式之后，原来复制的内容是否还在？光标是否回到原位？

   暂停很久（例如 1 分钟）之后继续，声音是否正常。
6. 切换音色：进度条是否正常，任务管理器里内存是否保持在 400MB 以下。
7. 修改两个快捷键、停顿时长后，重启程序设置是否还在；故意设成 Ctrl+C 或两个相同的键，是否被拒绝。
8. 高分辨率屏幕（125% / 150% 缩放）下，悬浮小人、菜单和设置窗口的文字、按钮是否清晰、没有被截断。
9. 右键菜单 → 选择音色能否正常选择；点小喇叭能否试听；点菜单外面菜单能否关掉（悬浮小人是“不抢焦点”窗口，需要确认菜单在这种窗口上工作正常）。
13. v0.4：选中一段文字（记事本、Word、浏览器）后单击小人或按快捷键，是否只读选中部分、读完自动停、选中状态没有丢。
14. v0.4：用右键菜单「导入音色包…」从 U 盘 / 中文路径导入音色包；把音色包直接复制进 voices 后（重启程序）右键 → 选择音色里能否出现；删掉文件夹后是否消失。
10. 4GB 内存的老电脑上是否流畅。
11. 在命令行窗口 / 资源管理器里按快捷键：应提示“这个窗口不支持朗读”，不应有任何按键效果。
12. 打开 Win+V 剪贴板历史，在一个 UIA 读不到的编辑器里朗读一次，看历史里多了几条（预期最多 1 条）。

## v0.6 补充：常见问题

- **提示“……是以管理员身份运行的，Windows 不允许普通程序读取它”**：目标程序（比如以管理员身份打开的记事本）权限比本程序高，
  Windows 不让普通程序读它。右键 `CaretReader.exe` →「以管理员身份运行」即可。
- **网页、PDF 里点了没反应 / 提示“请先选中文字”**：网页和大多数 PDF 阅读器没有可以放光标的地方，
  请先用鼠标**选中**要读的文字，再单击小人或按快捷键。
- **想看本程序在你电脑上占多少资源**：双击 `资源实测.bat`，等约 2 分钟（右下角会出现一个小人自己动，不用管它），
  结果写在同一个文件夹的 `资源实测结果.txt` 里。
