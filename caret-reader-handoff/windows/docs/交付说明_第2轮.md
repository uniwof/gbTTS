# 第 2 轮交付说明（v0.7-r2）

## 改了什么
- 每句合成后自动去掉模型自带的首尾静音，停顿改由标点表按秒数控制（×全局倍率 ×音色倍率，最长 3 秒）。
- 语速统一为「字/分」，默认 250（150–400）；每个音色自己测一次速度，换音色后节奏接近。
- 每个音色可单独微调语速和停顿，可一键恢复跟随全局。
- 新增 `tools/convert_piper.py`：把朋友导出的 Piper onnx 文件夹转成音色包（命令行）。

## 怎么用
- 设置 → 语速与停顿：调目标语速；打开「此音色单独调整」微调当前音色。
- 转换：`python tools/convert_piper.py <朋友的文件夹> <输出文件夹> --name 名字`，把生成的文件夹放进 voices\。用法见 tools/README.md。
