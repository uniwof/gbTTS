# 第 3 轮请你测（约 15 分钟，一共 9 条）

1. **托盘图标**：屏幕右下角找小图标。左键点一下，悬浮球消失；再点一下，悬浮球回来。右键能看到：开始/暂停、停止、选择音色、设置、退出。
2. **上一句 / 下一句**：在记事本里读一段话，读到一半按 Ctrl+Alt+PageDown，应跳到下一句；按 Ctrl+Alt+PageUp，回到上一句。
3. **朗读剪贴板**：在网页或 PDF 里选一段字，按 Ctrl+C 复制，再按 Ctrl+Alt+C，应该读出这段字。读完后你的剪贴板内容不变（随便粘贴一下看看）。
4. **读到一半换音色**：读的时候右键「选择音色」换一个，应该从刚才那一句接着读，不是从头来。
5. **音色列表**：打开音色列表，每个音色后面有「流畅 / 可用 / 可能卡顿」，流畅的排在前面。（刚装的音色要先用一次，才会出现标签。）
6. **停止**：读的时候点 ■（或 Ctrl+Alt+S），立刻停住。
7. **不抢焦点**：在 Word 里读，上面几条操作之后，Word 里的光标还在原来的位置，接着打字没问题。
8. **老电脑**（找一台 4G 内存的电脑）：解压运行，读一篇长文章 5 分钟。请告诉我：有没有卡顿；任务管理器里「光标朗读」占多少内存（超过 400MB 请告诉我）。
9. **别的软件占了快捷键**：如果启动时提示某个快捷键被占用，告诉我是哪一个。
