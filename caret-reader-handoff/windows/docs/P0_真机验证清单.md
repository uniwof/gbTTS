# P0 真机验证清单（取文字 + 悬浮球）

> 能自动化的部分已经写成测试，每次提交在 GitHub Actions（windows-latest）上自动跑：
> - `tests/CaretReader.Tests/GrabRulesTests.cs`：各类窗口里“剪贴板备用方式”允许 / 禁止什么（终端、资源管理器、远程桌面绝不发 Ctrl+C）。
> - `tests/CaretReader.Tests/NativePathsTests.cs`：中文路径不会让引擎崩溃。
> - `CaretReader.exe --selftest`：在真 Windows 上加载“清朗”音色并合成一句话。
>
> 下面这些**必须在真 Windows 上由人操作**（CI 机器没有桌面和声卡）。测试人：所有者或测试机。
> 每一项记录三件事：**能不能读**、**用的是哪种方式**（日志里写 UIA 或 剪贴板）、**焦点有没有丢**（读完后光标还在原处、能继续打字）。

## 二、P0 验收（文档第 15 节）

| # | 项目 | 标准 | 结果 |
|---|------|------|------|

## 怎么拿到测试包

GitHub 仓库 → Actions → windows-build → 最新一次 → 下面的 “gbTTS-portable-win10x64” 下载，解压到 `D:\gbTTS` 这类纯英文路径，双击 CaretReader.exe。
