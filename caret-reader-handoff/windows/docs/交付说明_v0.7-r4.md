# v0.7-r4 横条界面

改了什么：主界面从悬浮球改回 v0.5 的横条（黑白灰、左侧黑色墨条可拖动），只多一个「■ 停止」按钮。所有功能和逻辑不变；旧设置照常读取。

怎么用：点「开始/暂停/继续」；「■ 停止」立刻静音；点中间的下拉框选音色；右边「设置」；右键横条有更多菜单；托盘图标左键显示/隐藏。

请在电脑上测（≤8 条）：
1. 按住左侧黑条拖动横条，重开后位置还在。
2. 点下拉框换音色，记事本里的光标/选区不丢（不抢焦点）。
3. 开始 → 暂停 → 继续，按钮文字和反白正确。
4. 朗读中点 ■ 停止，声音立刻停。
5. 记事本、Word 各读一段。
6. 设置能打开，保存后正常。
7. 托盘图标还在，右键菜单正常。
8. 从旧版升级后，音色、语速、热键、词库设置都还在。
