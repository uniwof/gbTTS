# 更新说明（写给使用者）

## P1 文本层（2026-10-30，dev）
- 读法规则引擎：rules/*.tsv + data/用户读法词库.tsv（替换/模板/读音，整词、不分大小写、停用；最长匹配，用户优先；写错的行标红）。
- 数字与符号统一读法（日期、时间、百分数、手机号、单位、货币、版本号等，测试集 211 条）；字母逐个读（GDP、A 计划）；网络用语包 52 条。
- Markdown 清理（AI 回答里的 # * ` 表格、代码块）。
- 新停顿模型：标点表（前停顿、合并取最大）、段落/标题/列表项停顿、自动标题识别、长句衔接间隙。
- 设置 →「读法与标点…」：规则表格 + 测试框；标点表编辑。
- 旧版五档停顿、旧用户词库自动迁移（原文件保留）。

## 第 3 轮（v0.7-r3，2026-10-30，dev）
- 本机测速：音色标「流畅 / 可用 / 可能卡顿」并排序；首次启动按维护者排名选默认音色。
- 托盘图标、上一句/下一句（Ctrl+Alt+PageUp/PageDown）、朗读剪贴板（Ctrl+Alt+C）、朗读中换音色从当前句继续。
- 评审后小修：右键菜单带 WS_EX_NOACTIVATE；点 ■ 时试听样本音一起停。

## v0.7（P0，开发中）

- 程序现在每次修改后都会在一台真正的 Windows 电脑（GitHub 提供的云端电脑）上自动编译、自动测试，并且真的加载“清朗”音色读一句话，确认能出声。以前的版本从没在真 Windows 上跑过，这一步就是为了把隐藏的问题提前找出来。
- 每次自动构建都会生成一个可以直接解压使用的便携版压缩包（带“清朗”音色）。
- 悬浮小人旁边新增 ■ 停止按钮：朗读或暂停时，它会从小人身后滑出来（在离屏幕边缘远的那一侧），点一下就停止；不读的时候自动收起。
- 取消了“双击停止”。现在单击小人立刻就开始读或暂停，不用再等半秒。
- 拖动小人时，按住后移动超过一点点（4 像素）才算拖动，不会把点击误当成拖动。
- 点 ■ 和点小人一样，不会让正在编辑的文档失去光标。
