# P1 测试清单（每步一句）
1. 解压新的预览版 zip，双击 CaretReader.exe（旧版的设置会自动搬过来）。
2. 在记事本写「YYDS！我昨天读了《三体》——真好看……」，点小球，应读成“永远的神”，书名前后有短停顿。
3. 写「2026年10月30日10:30，气温25℃，降水概率30%。」，数字、温度、百分数都读对。
4. 写「请拨打13800138000」，号码一位一位读，1 读“幺”。
5. 写「他把GDP、PPT和MP3都讲清楚了，A计划比B计划好。」，字母一个一个读。
6. 打开设置 →「读法与标点…」→ 添加一行：替换 / 宝宝 / 宝贝，在测试框输入“宝宝好”，下面显示“宝贝好”。
7. 再加一行：读音 / 银行 / yin2 hang2，保存后读「银行行长在重庆重新开了一家银行。」应读对。
8. 在「节奏（标点）」页把逗号后停改成 0.6，保存后读一句带逗号的话，逗号处明显停得更久。
9. 粘贴一段带 ## 和 ** 的 AI 回答，# * 符号不读，标题后停顿稍长。
10. 有任何读错的句子，把原句发给我就行。
