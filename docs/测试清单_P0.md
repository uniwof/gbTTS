# P0 测试清单（每步一句）
1. 下载预览版 zip，解压，双击 CaretReader.exe，屏幕出现小球。
2. 在记事本里打几行字，光标放中间，点小球，听到朗读。
3. 朗读时再点一下小球，暂停；再点，继续。
4. 朗读时点球旁的 ■，立刻停止。
5. 鼠标停在球上约 1 秒，出现小工具条（■、音色），移开后消失。
6. 在球上快速双击，应取消并停止，不会乱读。
7. 轻微拖动球（几个像素）不应被当成拖动，大幅拖动才移动。
8. 单击右下角托盘图标：球隐藏；再单击：球出现。
9. 右键托盘图标：菜单有开始/暂停、停止、音色、设置、退出。
10. 提示气泡字够大、约 2.5 秒消失、不抢走记事本的输入焦点。
